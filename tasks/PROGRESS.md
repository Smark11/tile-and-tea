## M0.1b Screenshot harness
- `npm run screenshots` (`scripts/screenshots.mjs`) starts `expo start --web` on port 8099 (override with `SCREENSHOT_PORT`; it refuses a busy port), waits for Metro's `/status`, then uses Playwright Chromium to capture each route at 393×852 @3x (1179×2556, the real iPhone 15) in light and dark mode into `app/screenshots/<route>-<scheme>.png`. It clears old PNGs first and stops the dev server's process group afterward.
- Routes are found automatically from `src/app/` (`scripts/routes.js`, unit-tested in `scripts/__tests__/`). It skips layouts, `+` files, API routes, native-only variants, and dynamic `[param]` routes. Groups are stripped. Set `SCREENSHOT_ROUTES=/,/dev/styleguide` to capture a subset. Dynamic routes need a future harness option if we want them.
- Page JS errors and console errors make the run exit 1, so a broken screen can't pass silently. There's a 1s settle delay for entrance springs.
- One-time setup on a new machine: `npx playwright install chromium` (the script prints this hint if the browser is missing). Playwright is a devDependency.

## M0.2 Design system
- `src/theme/`: `palette.ts` (raw brand colors), `colors.ts` (semantic light/dark `ThemeColors`; use these, never raw hex), `tokens.ts` (spacing, radii, `boxShadow` elevations per scheme, typography, `minTouchTarget` 48, `maxContentWidth`), `fonts.ts`, and `useTheme()`. Fonts are Fraunces (serif headings) and Inter (sans body), loaded per weight. Each face is its own family name (`Inter_600SemiBold`), so set `fontFamily`, not `fontWeight`. The root layout holds the splash until fonts load.
- `theme.test.ts` asserts WCAG AA (4.5:1) for every text/background pair the components use. Add new pairs there when adding color tokens. Gold and red have separate `goldText`/`dangerText` variants because the brand values fail AA as text on light backgrounds.
- Components: `Text` (variants; headings auto-announce as headers; only big headings cap Dynamic Type scaling), `Button` (primary/secondary/quiet, Reanimated press spring skipped under Reduce Motion; use `sv.get()/set()` because the React Compiler lint rejects `.value` writes), `Card` (surface/felt), `Screen` (safe area + centered column). The styleguide lives in `components/dev/Styleguide.tsx`, and the `/dev/styleguide` route redirects home in release builds.
- Web is SSR (`web.output: server`), so `theme/useColorScheme.web.ts` returns light until hydration to avoid mismatch errors. Jest: `jest.setup.js` mocks safe-area and has a **minimal hand-written Reanimated mock**, because Reanimated 4's bundled mock boots native Worklets and fails under jest-expo. Extend that mock when you use more of the Reanimated API. RNTL v14's `fireEvent` is async, so `await` it.
- Screenshot harness now also pages through long scroll views, writing `<route>-<scheme>-2.png`, `-3.png`, and so on, so reviewers see below the fold.

## M0.3 Tile model
- `src/game/tiles.ts`: `TileKind` is a discriminated union (`suited`/`wind`/`dragon`/`flower`/`joker`) describing what a tile *is* for play. `Tile` is a physical tile `{ id 0–151, kind, copy }`. Compare kinds with `tileKey()`/`sameKind()` (keys look like `bam-3`, `wind-N`, `dragon-white`, `flower`, `joker`), never by object identity. `ALL_KINDS` (36 kinds) is in sort order: Bams, Craks, Dots, Winds (N E W S), Dragons, Flower, Joker.
- All 8 flowers are a single kind, as in American play. M0.4 can vary the flower art by `copy` (0–7). The Soap is `dragon: 'white'`. Its name is "Soap" and its a11y label is "White Dragon, Soap".
- Names: `tileName` gives the table shorthand ("3 Bam", "North", "Red", "Soap"). `tileA11yLabel` gives spoken words with no digits ("Three of Bamboo", "One of Characters", "North Wind").
- `src/game/rng.ts`: `createRng(seed: number | string)` (Mulberry32, with FNV-1a for string seeds) and a non-mutating Fisher–Yates `shuffle`. A test pins the first outputs for seed 42. Changing the RNG would break every saved seed, so don't. The dragon↔suit pairing (Red/Craks, Green/Bams, Soap/Dots) is left for M2.
- Review fixes: `coverage/` is now in `app/.gitignore` (the stray output was deleted). A golden-deal test pins the first 8 tiles of `createShuffledTileSet(createRng(42))`, so reordering `ALL_KINDS` or `createTileSet` breaks it on purpose. `WINDS` (N E W S) is only the listing order, not seat or turn order. Turn order (E→S→W→N) needs its own constant when play is built.

## M0.4 Tile component
- `components/tile/TileFace.tsx` draws every face in SVG (react-native-svg) in a 100×140 box: jade back layer, ivory body edge, gradient face with bevel highlight, plus a corner index (rank or N/E/W/S). The 1 Bam is a songbird, Dots/Bams use traditional pip layouts, Craks/Winds/Red/Green use system serif CJK glyphs (Hiragino Mincho on iOS, `serif` on Android), and the Soap is a blue double frame. The 8 flowers get distinct prints chosen by `copy` (0–7). Faces are 34 kinds + 8 flower prints = 42, plus the Joker. Ink colors live in `theme/tileInks.ts` and are AA-tested against the face.
- `components/tile/Tile.tsx`: `<Tile kind copy size="S|M|L" selected hint disabled onPress onLongPress>`. Pressing lifts and tilts it on a spring. Selected tiles rise and get a gold ring, and hinted tiles get a pulsing jade glow plus a star badge, so color is never the only cue. Disabled tiles dim. `Haptics.selectionAsync` fires on press (skipped on web). Under Reduce Motion there's no tilt or pulse, and selection snaps up without a spring. With no handlers the tile is `role=image`; with handlers it's `role=button` with selected/disabled state. The label is `tileA11yLabel` plus ", suggested" when hinted. Widths are S 30 / M 44 / L 64 at a 1.4 ratio. S is display-only (too small for a primary tap target), so M0.5's rack must budget its width for 14 tiles.
- On web, react-native-svg's `rotation`/`origin` props and RN a11y props on `<Svg>` leak to the DOM and fail the screenshot harness. Use `transform="rotate(a x y)"` strings instead (see the `rotate` helper). The Jest Reanimated mock now covers `withRepeat`, `withSequence`, `cancelAnimation`, and `Easing`.
- Added deps via `npx expo install`: `react-native-svg`, `expo-haptics`. The styleguide's new "Tiles" section on felt shows every face (tap suit tiles to select them), plus sizes and states.
- Review fixes: display-only tiles now pass `disabled={undefined}`. Pressable folds any non-null `disabled` into accessibilityState, which made VoiceOver read static tiles as "dimmed", and a test now guards this. Press handlers use `useCallback`, so **M0.5's rack must pass stable `onPress`s** to get the benefit of `memo`. Long press fires a Light impact haptic. Gradient ids are unique per tile through `useGradientUid` (`useSyncExternalStore`: plain ids while hydrating, a counter suffix after). `useId` caused hydration mismatches because Expo's server and client trees differ. The Jest Reanimated mock's `useReducedMotion`/`withSpring`/`withRepeat`/`cancelAnimation` are now `jest.fn`s, so tests flip Reduce Motion with `jest.requireMock`. A hint ring gets a testID of `${testID}-hint-ring`.

## M0.5 Rack component
- `game/rack.ts`: `sortRack` (ALL_KINDS order: Bams, Craks, Dots 1–9, Winds N E W S, Dragons, Flowers, Jokers last; ties broken by copy, then id, so it's stable), `isRackSorted`, and `moveTile` (a generic worklet-safe move with clamping). `components/rack/rackLayout.ts` holds the geometry worklets (`rackLayout`, `slotOrigin`, `slotAt`). Both are unit-tested.
- `components/rack/Rack.tsx` is **controlled** (`tiles` + `onReorder`; the parent must feed the new order back in). Decision: tiles never shrink below 40pt, so on a phone 13–14 tiles wrap into two tiers (7+7 / 7+6) on a lacquered jade tray with ledges. Wide columns (tablet, web at 640) fit one tier. Tap selects (`onToggleSelect`, `selectedIds`/`hintIds`/`disabledIds`). A sideways slide (`activeOffsetX ±8`, `failOffsetY ±16`, so vertical swipes still scroll) picks a tile up; neighbours glide aside on the UI thread through a shared `order` of ids, and the drop calls `onReorder` once. There's a haptic on lift, slot change, and drop. Reduce Motion snaps tiles into place instead of springing. Screen-reader users get "Move left"/"Move right" actions per tile. The "Sort by suit" button reads "Sorted by suit" (disabled) once sorted.
- Gesture Handler v3 hook API (`usePanGesture` + `GestureDetector`). The root layout now wraps everything in `GestureHandlerRootView`, and **tests that render a Rack must wrap it too**. Jest loads `react-native-gesture-handler/jestSetup.js`, mocks `react-native-worklets` (`scheduleOnRN` calls through), and the Reanimated mock gained `useAnimatedReaction` and `isSharedValue`. Drag is tested with `fireGestureHandler(getByGestureTestId('rack-tile-<id>-drag'), …)` inside `act`.
- `Tile` gained `width` (an exact-size override) and `accessibilityActions`/`onAccessibilityAction`. Rack colors (`rackTray`, `rackLedge*`) live in `tileInks` because the rack is a physical object and doesn't change with the color scheme. The styleguide has a new "Rack" section with a seeded deal. Drag has only been exercised in Jest and on web, not yet on a physical device (the checkpoint after M0.6 covers that).
- Review fixes: only one tile can be lifted at a time. `onActivate` returns early while `draggingId` is set, so a second finger can no longer strand the first tile lifted and off its slot. A `createGestureController` test interleaves two drags, and it fails without the guard. Each drop bumps a `drops` counter that re-syncs `order` from `tiles`, so if the parent ignores `onReorder` the tile glides back and the screen matches `tiles` and the a11y actions. `handleDrop`/`handleMove`/`handleSort` read `tiles`/`onReorder` from a ref, so they keep one identity and `memo` on `RackTile` holds.
- The Jest Reanimated mock's `useAnimatedReaction` now behaves like the real one. It keeps `previous`, honours `deps` (previous resets to null), and re-runs on any shared-value `set`, so springs after a sort or a drag are testable (`withSpring` spy).

## M0.6 Navigation shell
